## 驗證範圍

沿用已確認的 Playwright 使用者操作＋HTTP 攔截邊界；未提交雲端照片或回報，未測真實 GPS、相機、實體手機或後端距離計算本身。

新增三種情境在桌面及手機各執行：示意 PNG／所選桶座標／明示確認／原命令重試；過遠與定位失敗後恢復／延遲 GPS 隔離；長說明保留／種類草稿隔離／320px 無橫向溢出。既有真實照片、快捷通報、停權與其他流程保留回歸。

啟動及手動操作見 [前端 README](../frontend/README.md#串接後端的回報模擬測試)。本機預覽使用 5173；完整測試使用另一個 Vite dev server 的 5174，因歷史展示不包含在 production dist 中，且所有 API 都由測試攔截。Vite 大型 bundle 警告仍存在。
