# 後端回報頁的模擬輸入工具

2026-10-20，依使用者要求將歷史展示的示意照片、距離及定位失敗測試搬到正式 API 回報頁；所選桶的 API 經緯度可一鍵帶入。

- 正常回報及有效認養快捷通報共用工具；不讀取歷史展示帳號、案件或點數。
- 示意照片為 640×480 PNG，明示 DEMO／模擬測試／非現場照片；經原照片驗證、私有媒體上傳及回報 API。
- 一鍵所選桶座標模擬距離 0 公尺；過遠情境向北偏移約 78 公尺，實際 50 公尺判斷仍交給後端。失敗情境清空座標並取消確認。
- 保留真實照片與 GPS 入口；使用模擬座標後需自行勾選模擬位置確認，舊 GPS 回呼不能覆寫新情境。手動編輯座標不會移除已使用模擬位置的標記。
- 回報說明自動附模擬來源標記，計入既有 500 字上限；超長時保留原文並阻擋送出，不截斷文字。照片浮水印與文字標記不等於後端新增獨立的 demo 欄位。
- 桶／垃圾種類／快捷認養分開保留草稿；未知結果凍結輸入，重試保留原 body、key 及已上傳媒體。市民角色、停權、認養與桶生命週期限制維持原 API 流程。

## 驗證範圍

沿用已確認的 Playwright 使用者操作＋HTTP 攔截邊界；未提交雲端照片或回報，未測真實 GPS、相機、實體手機或後端距離計算本身。

新增三種情境在桌面及手機各執行：示意 PNG／所選桶座標／明示確認／原命令重試；過遠與定位失敗後恢復／延遲 GPS 隔離；長說明保留／種類草稿隔離／320px 無橫向溢出。既有真實照片、快捷通報、停權與其他流程保留回歸。

啟動及手動操作見 [前端 README](../frontend/README.md#串接後端的回報模擬測試)。本機預覽使用 5173；完整測試使用另一個 Vite dev server 的 5174，因歷史展示不包含在 production dist 中，且所有 API 都由測試攔截。Vite 大型 bundle 警告仍存在。

## 執行結果

- `npm run typecheck`、`npm run data:check`、`npm run build` 通過。
- 完整 `test:e2e` 執行 338 項：336 項通過；新增長說明案例的桌面／手機兩項因測試定位方式失敗，改以 textbox role 與切換後重新查找 radio 後，`--last-failed` 兩項均通過。產品程式在此重跑期間未改動。
- 已檢視 1440px 桌面及 320px 手機截圖，無橫向溢出；另在 5173 production preview 使用實際 API 桶讀取一鍵座標與示意照片預覽，未上傳或送出。
