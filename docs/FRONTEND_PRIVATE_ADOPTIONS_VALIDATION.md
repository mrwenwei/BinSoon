# 市民私人桶名與認領上限（2026-10-21）

使用者要求取代原提案人公開命名：每位認領者均可各自為 Bin友命名，無須審核、僅自己可見，不限第一位認領者。每人有效與待審認領合計至多 5 個；認領時必填 1–50 字私人桶名，有效認領可再更名。

本輪實作在預設市民本機展示帳本。新認領立即在本機啟用；不改後端資料、資料庫、公開 Bin 名稱、角色或雲端部署。後端模式仍保留舊 API 的公開認養／提案命名審核契約，正式多人帳號尚需後端另行遷移，不能將展示的瀏覽器隔離視為伺服器授權。

- 模擬市民預建「全家炸雞桶」、「下班等公車桶」、「早餐店轉角桶」；原帳本升級保留原案件、點數、投票、已結束認領及既有私人名稱，補入展示時不超過上限。
- 私人名稱只投影至登入展示帳號的地圖、單點及個人認領；Bin ID、地址、座標及來源不變，未登入不顯示。其他公開認養者不阻擋本人的本機認領。
- 介面檢查與送出端均限制 5 個；既有跨分頁鎖保證同時送出不超額；結束後釋出名額，同一人不可重複認領同一桶。
- 停用市民展示的提案命名審核入口及舊本機 name-requests 操作；提案投票說明改為私人命名規則。

## 驗證

`typecheck`、`data:check`、`build`、`git diff --check` 通過。指定認養、地圖、市民展示、投票及新增私人認領共 56 項桌面／手機測試：首輪 54 項通過；另 2 項原測試嘗試點擊已因五桶上限停用的按鈕，已改驗證停用狀態並獨立驗證送出端拒絕第六桶。重跑私人認領及投票共 10 項全通過。未重跑整套測試。

新測試驗證同桶已有他人認養仍可認領、命名／更名、重整保留、未登入不顯示、無後端寫入、跨分頁停用第六次申請、直接命令仍被拒絕、結束後可認領新桶。桌面／手機模擬截圖已檢視；本機 5180 實際頁面確認顯示三個預建名稱。未驗實體手機或正式多人帳號。
