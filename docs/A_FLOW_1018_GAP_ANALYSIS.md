## 共通規則差異

- 初版依回報類型給 5／10／30 點；新版統一屬實 +1、認養者 +2。尚待審核不入帳，同一事件只獎勵第一位。
- 六級門檻：見習生 0、新手 10、獨當一面 50、高手 150、專家 500、教授 1000；門檻在 PM 文件中標示為暫定。
- 獎品兌換扣可用點數，不扣累積點數，不使等級下降。舊展示帳本只有 230 點及單一已兌換旗標，不能直接當成新版帳本使用。
- 本版 PRD 明確退出預約小車、車上垃圾友善點、遛狗模式與狗便袋回報；舊集章也不在 P1–P9 的會員集點流程中。
- 仍保留 681 筆公布桶位置、130 筆場所代表點的來源界線，代表點不套用桶況／回報。先前使用者已要求移除 150m 參考圈，本次不恢復。
- 缺桶 P10、投票 P11–P13、認養 P14–P16 為 B flow；清潔員 P17–P22 為 D flow。A 的跨流程入口先作範圍提示，不能將整份 ABD PRD 視為已授權全部實作。
