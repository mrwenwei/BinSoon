# 市民本機展示與 Bin友用語

2026-10-21 使用者要求：展示多樣桶況、精簡桶詳情、免密碼假市民／假會員資料，並把介面電子雞改稱 Bin友。另已確認回報／提案／投票也改為本機展示，不寫後端。

## 實作邊界

- API 原始資料及資料庫不變。`demoBins` 在前端接收公開點位後，按 Bin ID 與垃圾種類穩定投影多種滿度；雙槽分開，維修／撤除／尚未設置限制保留，places 不變成 bins。API 失敗仍顯示失敗，不用假點位掩蓋錯誤。
- 市民預設展示模式；後端模式與後台真實角色仍保留。假身份只作本機識別，任何公開讀取都移除假 Authorization，所有假市民寫入都在本機處理，未支援路徑明確拒絕，絕不 fallback 到雲端。
- 展示帳本獨立命名、版本化保存於 localStorage，照片為本機 data URL；登入記號在分頁 sessionStorage，無密碼或真實 session。展示帳本不覆寫舊 legacy key 或後端個資。
- 預設會員資料含三筆屬實與一筆待確認的示意案件；累積 128 點、已兌換 35 點、可用 93 點、待確認 2 點。真實操作只更新本機展示帳本，不會發點、停權或派工至後台。
- 提案保留待現勘含義；附近提案可確認不同需求，支持／反對／撤回維持一人一票，達 60 票會依示意門檻關票，仍不表示設置。展示模式只檢查座標格式及展示點位的距離，不冒充後端 PostGIS、行政區或現勘驗證。
- 本機讀寫經序列化、交易副本與原命令 receipt 保持重試不重複扣點；Web Locks 支援時也保護同源跨分頁操作。儲存不足不提交該次變更，顯示錯誤且不改送後端。多分頁的會員點數同步更新。
- 詳情只移除指定區塊與歷史請求；未刪後端歷史、來源追溯欄位或分類證據。地標的代表點說明維持。
- UI 文字（含歷史展示入口）統一 Bin友，Bin／bins 與 waste_type 模型不改名；設計系統產生檔的歷史註解不屬於介面文字。

## 驗證方法

沿用已確認的 Playwright 使用者操作＋HTTP 攔截邊界。舊 API 契約測試明確選後端模式，新的市民測試選展示模式，避免把假資料測試當成後端整合已通過。

新測試涵蓋：0／50／100% 與輪詢／重整一致；bottom sheet 不再出現兩個區塊及歷史請求；免密碼登入、假會員與重整保留；本機照片回報／提案／改票撤票／兌換閉環；通知與認養偏好／結束；頂欄點數同步；兩分頁防重花點；儲存失敗時不寫入後端；桌面及 320px 畫面。

測試攔截檢查所有市民請求，不允許後端 POST／PATCH／DELETE 或假 Authorization。未對雲端建立案件、提案、照片、投票或兌換。未驗證實體手機、真實 GPS／相機及無 Web Locks 的跨分頁競爭。
