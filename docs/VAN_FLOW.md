# 預約小車（2026-10-23）

分支：`codex/van-reservations`。依使用者提供的 C1／C2 與 D1／D2／D3 截圖配置，沿用既有深色 chrome／panel、mint 選中、teal CTA、字體及圓角 token，不改成截圖黃白色票。

市民 `#van` 提供明天起七天的日期、早晚班與五站選擇、預約詳情、再次預約、修改、取消及系統分享（不支援時複製）。同日期同班別只能一筆。日期依台北時區計算，前一天 20:00 公布路線；公布後停止修改與取消。

清潔隊 `#crew/van` 提供日期／班別、總人數、開站及併站、路線順序、導航、到站十五分鐘倒數及下一站／本班完成。全部為本機互動，不需 API 或真實清潔員憑證。預約使用獨立 `binsoon-van-v1` localStorage，同源分頁可同步；清潔員工作進度只保留目前頁面。

五個站的基礎人數、位置、距離與道路為固定展示假設。十人開站，不足者按展示座標距離併入最近開站點；不修改 Bin 模型、原始 CSV、桶況或歷史。未接 GPS、道路導航服務或正式派車，分享不包含個人資料。

驗證：typecheck、data:check、build、git diff --check 通過。新增 Playwright 在桌面及 Pixel 7 各驗證預約日期七天、重整保留、修改／取消、兩端人數、到站倒數、下一站、無 `/api/v1/` 請求及橫向溢出，共四項通過；已檢視兩端桌面／手機截圖。完整 test:e2e 已啟動，22 通過、5 失敗、2 中斷、471 未執行後停止；失敗涉及 api-completion／api-governance 的桶況與提案流程，未證明為基準既有失敗，本次不宣稱完整回歸通過。實體手機、系統分享與剪貼簿權限尚未驗證。Vite 仍有既有設定及 bundle 大小警告。
