# 市民端 UX 改版規格（地圖、桶資訊、回報）

2026-10-19 依 UX 走查（新版 API 前端＋設計系統）與使用者逐項討論確認。實作待 `feat/frontend-v0` 合併進 main 後於 `feat/ux-layout-flow` 進行。設計系統既有規劃（[DESIGN_SYSTEM.md](DESIGN_SYSTEM.md)「選桶後在地圖下方浮出桶況卡」）與本規格一致。

## 地圖首頁

| 項目 | 決定 |
| --- | --- |
| 版面 | 以地圖為主。手機下方為可上拉／下收的抽屜面板（類似 Google Maps）；桌面維持左側面板，行為與抽屜相同。 |
| 未選桶 | 面板顯示「附近的桶」：合併原「最近的可用小夥伴」與「位置清單」為同一份清單，依距示範起點距離排序；每列顯示桶名、距離、步行時間、可丟槽數（如 2/2）。篩選一致套用到整份清單，預設顯示全部。 |
| 選桶 | 地圖放大移到該桶，面板改為該桶資訊；關閉回到清單。`#bin/<id>` 開啟即為「地圖＋已選該桶」，移除獨立桶頁中的小地圖。 |
| 行政區 | 移除「探索範圍」下拉，只留搜尋框；資料改讀全台北市，地圖預設以示範起點為中心。 |
| 類型切換 | 移除「全部／公布桶位置／場所代表點」，預設全部顯示。 |
| 篩選 | 整合為一排：全部（預設）｜還能丟｜新設｜建議點（取代「包含建議點／待現勘」勾選框）。 |
| 場所代表點 | 標記改為地標圖示，不用電子雞造型；點選顯示「這是地標，不是垃圾桶，周邊約 N 處清潔箱」。 |
| 起點 | 地圖加「起點（示意）」標記，說明距離從哪裡算。 |

## 桶資訊（面板）

- 移除「今天的飽足度」：它重複顯示一般垃圾槽的百分比。改為每槽一條滿度條，旁附一行「更新於 X 前」；每槽可加「約 N 小時後滿」（後端 `estimated_hours_to_90_pct`）。
- 移除「滿度與清運歷史」清單（隊員頁保留）；改為一行「上次清空：X 前」（`last_emptied_at`）。
- 清運感謝改為訊息條：只在有可驗證清運完成紀錄時出現；手機貼在抽屜面板上方，桌面在地圖下方中間。同一次清運按讚或關閉後不再出現。未登入顯示「登入後按讚」。按讚後顯示「謝謝你！已有 N 人感謝」並自動收起。面板內保留一行「上次清空：X 前 · 👍 N」。
- 按鈕：「導航過去」為 primary（實心）；「回報狀況」為 secondary（外框），兩者同一排。
- 桶不可用（吃飽、失聯、維修、撤除）時：上方一行「這桶吃飽了 · 最近可丟：〈桶名〉（N 分鐘）」，主按鈕「改去附近的桶 →」。替代桶以該桶座標與槽別呼叫 `/map/nearest-usable`（不再以示範起點找，避免改導到他區）。
- 不能回報時，「回報狀況」照常顯示但停用，並寫明原因（例如「已撤除，無法回報」）。

## 回報表單

- 標題「回報狀況」。回報類型維持後端五種與現有名稱；不依桶況預選。
- 順序：① 發生什麼事（五個按鈕，不預設）→ ② 哪一槽（一般垃圾／資源回收）→ 說明（選填；選「其他」時標示必填）→ ③ 照片 → ④ 位置。
- 照片：「拍照或選照片」按鈕，選後顯示縮圖；說明改為「一張照片，5MB 以內」。
- 位置：「使用我的位置」一鍵取得，直接顯示「你距離這個桶約 N 公尺」與是否在 50 公尺內；經緯度欄位收進「手動輸入」，僅定位失敗時使用。「確認這是我提供的現場位置」為前端自加（後端無此欄位），只在手動輸入時出現。
- 送出鈕上方列出「還差：…」。
- 訪客：直接進表單，頂部提示「送出前需要登入，你填的內容會保留」；主按鈕「登入並送出回報」，登入後自動送出一次；送不出去時留在表單並以中文說明原因；登入頁從回報進入時顯示「返回回報」。
- 錯誤：後端錯誤代碼（如 `PROXIMITY_TOO_FAR`、`SESSION_EXPIRED`、`UNAUTHENTICATED`）對照成中文並附解法；登入逾時時表單維持顯示原草稿；重複回報時明說「你已回報過這個問題」並顯示原案件進度。

## 用語

移除英文小標（A LITTLE HELP…、AVAILABLE、FILL LEVEL、FROM、STATUS）、`simulated`、`reset`、`point_as_published` 等工程字串。依專案規則，示意資料仍須揭露：全站只保留一句白話「桶況為模擬資料，尚未連接真實感測器」。
