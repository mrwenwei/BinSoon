## 缺桶與提案

1. 300m搜尋涵蓋全市既有桶，不受目前行政區、來源或桶況篩選影響；排除場所、候選／投票提案及示意已移除桶。滿桶、狀態未知仍算既有桶。距離是選點至公布座標的直線距離，不是步行路網距離或真實定位。
2. 最近桶距離≤300m即不顯示缺桶；全部無既有桶時距離顯示無資料，不造出數值。缺桶只代表公布資料範圍內無桶，不等於已證明應增設。
3. 新增提案限畫面框出的「大安區示範範圍」，明示這不是精準行政區界驗證。實作時明確設定並顯示範圍；不暗稱已具備行政區多邊形。沿用示意起點，提供地圖點選／移動標記及座標輸入／確認替代入口。
4. 距既有桶≤150m只提示，不阻止提案。距既有提案≤50m先顯示相近提案，可改支持既有提案或確認繼續新增，不自動合併。
5. 名稱、原因及有效選點必填；座標採有限的 numeric 經緯度並驗證範圍。範圍外不允許送出。底圖失敗時保留清單／表單及明確提示。
6. 每人每台北時間曆月最多成功新增3點；只算新增，不算投票、改票、撤票。新增成功自帶一張支持票。本版無提案編輯／刪除。

## 投票與進度

每人每提案最多一票，支持或反對擇一；累積期間可改票或撤票。總投票人數＝支持＋反對，支持率＝支持÷總人數；零票顯示「尚無投票」。狀態判斷使用未四捨五入的比例，顯示百分比不得改變達標判斷。

展示門檻固定60人、支持率至少60%，標示示意，不宣稱取自實際人流。例：支持47、反對3時，總人數50/60、支持率94%、尚差10人，不能顯示47/60或尚差13票。

| 條件／操作 | 結果 |
| --- | --- |
| 總人數<60 | 累積中，可繼續投票、改票與撤票。 |
| 總人數≥60，支持率<60% | 需里長確認，結束該輪投票。 |
| 總人數≥60，支持率≥60% | 送評估，結束該輪投票。 |
| 展示控制確認里長同意 | 由需里長確認轉送評估，不宣稱支持率本身已改變。 |
| 評估通過 | 展示控制轉會勘中。 |
| 會勘通過 | 展示控制轉示範已設置；不自動新增真實桶。 |
| 評估／會勘未通過 | 顯示未通過與必填原因，不重開投票輪次。 |

結束投票後不能再投票、改票、撤票或隨票數反覆跳關。PRD 的人流評分、前20%等算法本版沒有接通，不能假稱計算完成。

## 設置成果、命名與分享

一般找桶地圖維持既有資料類型，提案僅在投票地圖及進度頁顯示。示範已設置只產生 B 的示範成果卡，不能寫入原始快照、後端清潔箱或候選點；681筆公布桶與130筆場所總數保持不變。認養主線仍選既有公布桶，不能把示範成果偷換成某個既有桶。

最早提案者在示範設置後可送出桶名，展示控制核准／退回；退回可重送，待審內容不覆蓋已核准名稱。桶名與認養者的公開名稱分開保存與呈現。

結果採本機站內提示。支持者使用「你催生了這個桶」，反對者使用中性設置結果文案。分享採原生分享或複製連結，明示其他裝置不會自動取得本機新增提案；不保證分享連結可跨裝置載入本機資料，也不建立公開提案發布服務。

## 認養生命週期

一桶同時一名核准認養者，一個示範帳號可認養多桶。不允許同帳號同桶重複待審／有效認養，已有其他認養者的桶不能申請；不模擬多帳號競爭。不設自動到期。

| 狀態／操作 | 權益與後續 |
| --- | --- |
| 送出申請→待審 | 無通知、公開認養名稱或加倍權益；可撤回。 |
| 展示控制核准→認養中 | 顯示認養名稱，開啟所選通知與首報加倍。 |
| 未通過／撤回 | 保留歷史；桶仍開放時可重新申請，必須重新核准。 |
| 本人結束認養 | 顯示影響並確認後結束；保留歷史，立即停通知及新回報加倍。 |
| 桶移除 | 終止認養權益並保留歷史，不能繼續新回報加倍。 |

撤回也顯示影響供確認。待審不占永久名額、不自動核准；不承諾3個工作天。三種通知為吃飽了、旁邊有堆放、很髒，可隨時修改，也可全部關閉。清運仍由清潔隊負責。月報等無來源數據採明示示意。

## A/B 共用回報與點數

- 回報頁由核准的認養關係決定身分，送出時保存資格；一般首報屬實+1，認養首報屬實+2。後來才核准不補倍；結束認養不追扣先前送出的案件。
- 快捷入口沿用 A 的登入、現場照片與距桶≤50m示範驗證，屬實審核後才入帳。本版不增加遠端轉送提醒。
- 同桶、同問題在未結案期間屬同事件。同帳號再次操作導向既有案件，不重複新增。結案後重新發生才建立新事件；不再永久封鎖同桶同類型。成功送出後清空該桶草稿，新事件須重新完成照片與距離驗證。
- 同事件只有原首報可能得點，後續回報為0；首報不實也不遞補。最終審核及入帳只完成一次，重整不能重複發點。
- 三次不實只暫停 A 回報及 B 快捷通報，仍可投票、提案與申請認養；不擴張為全面停權。
- 保留 A 會員累積／可用點數、兌換及舊帳本隔離規則。既有認養示意、回報身分開關及同桶永久去重須依本規格調整；不能讓同一桶在 A/B 顯示不同核准關係，也不能因儲存格式變更默默丟棄原有帳本。
