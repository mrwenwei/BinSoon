# A flow：民眾找桶與回報展示

2026-10-18 使用者確認本文件範圍，並指定使用 implement skill 實作。

來源：[PRD 桌面版](https://claude.ai/artifact/Eng4CbzrW5vFfRyWWViHf8#page-d63f1065a6ff)、[手機版](https://claude.ai/artifact/Eng4CbzrW5vFfRyWWViHf8#page-ed25c7b30423)。已讀取兩版畫面中的 A 民眾流程。

## 範圍

- P1 地圖：搜尋、十二區與資料類型篩選、車上垃圾／狗便便／活動／餓了篩選，地圖與可鍵盤操作的清單。
- P2 桶詳情：電子雞桶況、今日飽足度、導航、按讚、回報入口及印章。場所代表點仍顯示原始精度與來源，不套用桶況或回報。
- P3 回報及回報完成：桌面提供連至手機回報的 QR Code 和展示入口；手機選類型、模擬拍照、模擬 50m 定位驗證、登入後送出。其他類型需文字說明。
- P4 登入：示範台北通與手機驗證碼，保留登入前目的地，不使用真實憑證或發送簡訊。
- P7 集章／點數：230 初始點數、待確認回報點數、20 個印章、200 點換 50 元示意券，避免重複送出及重複兌換。
- 回報維持待確認，不自動發放點數；送出收集該桶印章，重複回報不重複收集。
- 小車、投票、認養、榮譽榜僅顯示尚未納入 A flow 的提示。

## 資料界線

原始 681 筆公布桶位置、130 筆場所代表點及 source_*、精度資料保持不變。所有新增桶況、認養者、時間、距離起點、集章與獎勵均屬清楚標示的示意資料。不新增後端、感測器或真實派工。資料庫與原始 CSV 不變。

示範帳號、按讚、回報、印章與兌換券保存在本瀏覽器；不儲存使用者輸入的手機號碼、真實相片或定位。儲存不可用時仍可於當次瀏覽操作，並提示限制。導航以公開桶座標開啟外部地圖，不傳送使用者定位。

## 驗證介面

沿用儲存庫既有 Playwright 瀏覽器介面，驗證使用者已確認的流程：找桶／來源區分、登入返回、回報阻擋條件與完成、待確認點數／印章／兌換及重新整理後保留。桌面與手機尺寸均測試；另檢查窄螢幕水平溢出、底圖失敗與未知網址。

執行 typecheck、data:check、build、test:e2e，並人工檢視桌面及手機截圖。實體手機、真實登入／拍照／定位／派工不在本次驗證範圍。
